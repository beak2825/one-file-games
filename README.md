# One-File Games ⚡

collection of fun, lightweight games that run entirely in a single `.html` file — no server, no installation, no internet required.

download an HTML file, double-click it, and play instantly in any modern browser. All graphics, sounds, and code are embedded using data URIs, base64, or pure generative code.

## For developers & contributors

add your own single-file game?

- Keep everything in one `.html` file
- Embed assets as data URIs or generate them with code
- [Make a pull request...](https://github.com/beak2825/one-file-games/pulls)
